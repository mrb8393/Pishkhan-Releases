## 📋 دربارهٔ پروژه

**Pishkhan Agent** یک ابزار سازمانی است که روی سیستمهای کارمندان شرکت سنگ آهن مرکزی ایران (ICIOC)
نصب میشود و خدمات زیر را ارائه میدهد:

- 🖥️ **مانیتورینگ لحظهای** منابع سیستم (CPU، RAM، Disk)
- 🎫 **ثبت تیکت پشتیبانی** به سرور مرکزی دانا
- 📊 **گزارش سختافزار و نرمافزار** سیستم
- 🔄 **بهروزرسانی خودکار** از سرور داخلی یا GitHub
- 🌐 **تشخیص اتصال شبکه** و گزارش وضعیت
- 🔍 **جستجوی نرمافزارهای نصب شده** (مثل RustDesk)
- 🛡️ **بررسی امنیت** (آنتیویروس، فایروال)

---

## ✨ ویژگیهای کلیدی

### 🚀 عملکرد بالا
- رابط کاربری **WPF** با پشتیبانی کامل از زبان فارسی (راستچین)
- بارگذاری غیرهمزمان اطلاعات (UI هیچوقت قفل نمیشود)
- استفاده از `Task.Run` برای کارهای سنگین در پسزمینه

### 🔐 امنیت و دسترسی
- **تشخیص خودکار** سیستمهای دامین شرکت
- **اعتبارسنجی لایسنس** برای سیستمهای خارج از دامین
- **Run as Administrator** با تأیید UAC
- **Task Scheduler** با Group-based Principal (BUILTIN\Users)

### 🔄 بهروزرسانی هوشمند
- **سه منبع بهروزرسانی**: سرور داخلی، GitHub، یا هردو
- **دانلود Chunked با Resume** (ادامه از جایی که قطع شد)
- **SHA-256 Verification** فایل دانلود شده
- **Atomic File Replacement** (جایگزینی امن فایلها)
- **Auto-rollback** در صورت خطا
